# QURANER ALO

## কোরআনের আলো — Online Quran Academy Management System

This repository is a clean rebuild from the ground up.

### Principles
- Security-first architecture
- Supabase for authentication, database, and storage
- GitHub Pages for the public web application
- Mobile-first responsive UI
- Modular school-management workflows
- No plaintext passwords
- No legacy prototype code

### Planned modules
1. Foundation & branding
2. Authentication & roles
3. Students & guardians
4. Teachers & helpers
5. Classes & attendance
6. Quran learning progress
7. Fees & receipts
8. Payroll
9. Income, expenses & vouchers
10. Reports, ID cards and print layouts
11. Parent and teacher portals
12. PWA / mobile experience

The system will be built incrementally and reviewed after each major step.
